> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Corregir todos los bugs Critical/Important/Minor del review en orden de severidad.

**Architecture:** Fixes inline por archivo en orden: CLI → common → search → install → update_books → tests + README. Sin cambios de arquitectura; solo correcciones mínimas verificadas por lectura.

**Tech Stack:** Nim 2.2.0, std/httpclient, unittest, libsha/sha256.

**Spec:** Elun.md (Fases 1-4, Comandos, Calidad de vida) + README.md.

## Global Constraints

- Nim >= 2.2.0.
- Comandos en inglés (Elun.md:52).
- Fase 3: test suites no se corren; `<pre class="root">` con sudo; carpetas sin versión; registro con MD5/prefijo.
- Fase 4: fallo compila → aborta + `.elun-failed.log`, no reintenta.
- Sin MD5 (GLFS/SLFS) se instala igual sobre TLS con aviso, sin reutilizar tarball viejo.

## Review Focus

- Input con HTML en mayúsculas/atributos variados debe parsear igual — tests no lo cubren todo.
- Registro JSON corrupto no debe crashear con stack trace — verificar mensaje.
- Tarball malicioso con `../`/symlink no debe escribir fuera del build — verificar por lectura.
- Libro ausente en checkout parcial debe descargarse, no decir "no existe".
- `remove` sin prefijo no debe hacer `sudo rm` sin confinar.
